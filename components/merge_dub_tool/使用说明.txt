合并视频 + 配音 便携工具
========================

【包含文件】
  merge_dub_videos.py   主程序（Python 标准库即可，无需 pip 安装包）
  合并配音视频.bat      Windows 双击运行
  merge_dub_videos.sh   macOS / Linux 终端运行
  使用说明.txt          本文件

【做什么】
  递归扫描你选的文件夹及子文件夹，在同一目录内：
    - 找「原视频」（.mp4 / .mkv 等，不含已生成的 *_C.mp4）
    - 找「配音」（.mp3 / .wav / .m4a，或仅有音轨的 .mp4 / .webm 录制文件）
    - 去掉下载序号（如 2-、2标题）后，再忽略开头 5 个字符，然后比较剩余部分
      （例：6- xxx.mp4 与 xxx.mp4 视为同名；前 4 个词一致即配对）
  输出：原视频名_C.mp4（画面 stream copy，原声丢弃，只留配音）
  时长：以视频为准 + 0.2 秒；配音更长则裁切，更短则末尾补静音

【配对示例】
  1 - Course Overview.mp4  +  1 - Course Overview.mp3
  或  1 - Course Overview.mp4  +  1 - Course Overview_C.mp3
  →  1 - Course Overview_C.mp4

【依赖 — Windows】
  1. Python 3.10 或更高（推荐 3.12）
     安装时勾选「Add to PATH」
     自带 tkinter（用于选文件夹）；若选窗打不开，用命令行：
       py -3.12 merge_dub_videos.py "D:\你的课程目录"
  2. ffmpeg + ffprobe（必须在 PATH）
     下载：https://www.gyan.dev/ffmpeg/builds/ （选 release essentials）
     解压后将 bin 目录加入系统环境变量 PATH
  3. 不需要 Kokoro / edge-tts / 其它 pip 包

【依赖 — macOS】
  1. Python 3.10+（python3 --version）
     选文件夹需要 tkinter；Homebrew Python 有时需：
       brew install python-tk@3.12
  2. ffmpeg：
       brew install ffmpeg
  3. 同样不需要 pip 第三方库

【Windows 与 Mac 差异】
  - 脚本逻辑完全相同，只是启动方式不同（.bat vs .sh）
  - Mac 没有「py -3.12」启动器，用 python3 或 python3.12
  - 都必须能命令行执行 ffmpeg -version

【用法】
  Windows：双击 合并配音视频.bat → 选 2 → 在弹窗里选课程根目录
  预览：选 1，只看匹配不写文件
  Mac：chmod +x merge_dub_videos.sh && ./merge_dub_videos.sh

【拷到别的电脑】
  整个 merge_dub_tool 文件夹复制即可（含 .py / .bat / .sh / 本说明）。
  Windows 与 macOS 通用同一套 merge_dub_videos.py，不必复制配音流水线其它脚本。

【macOS 一键安装依赖（终端）】
  # 若尚未安装 Homebrew，先装 Homebrew（见上表）
  brew install python@3.12 ffmpeg python-tk@3.12

【macOS 使用方法】
  cd /path/to/merge_dub_tool
  chmod +x merge_dub_videos.sh
  ./merge_dub_videos.sh
  # 选 1=预览  2=合并（弹窗选文件夹）  3=手动输入路径

【Windows 使用方法】
  双击 合并配音视频.bat → 选 2 → 弹窗选文件夹

【命令行（两平台通用）】
  python3 merge_dub_videos.py --pick-folder --dry-run   # Mac 预览
  py -3.12 merge_dub_videos.py --pick-folder            # Windows 合并

【用不了时排查】
  1. 命令行执行 ffmpeg -version 是否 OK
  2. py -3.12 merge_dub_videos.py --pick-folder --dry-run 看能否配对
  3. 同一文件夹内：去下载序号并忽略开头 5 字后，文件名一致（或前 4 词一致）
  4. 不要把「原视频」和「已生成的 *_C.mp4」搞混（*_C 会被跳过）

【与「批量配音.bat」的关系】
  批量配音.bat / run_batch_course.py  →  从字幕生成 mp3 再合并（大工具链）
  本工具  →  你已有视频 + 已有 mp3，只做最后一步合并
  本工具不依赖 step2_merge_video.py、dub_naming.py 等
