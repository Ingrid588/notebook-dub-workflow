Gemini API Key — 仅 Windows 用户/系统环境变量
==============================================

本项目只从环境变量读取 API Key，不读 .env、bat、tubeget.secrets.json。

推荐变量名：GEMINI_API_KEY
备选（按代码优先级）：GOOGLE_API_KEY 、 TUBEGET_GEMINI_API_KEY

设置步骤（Windows 10/11，对本用户永久生效）
------------------------------------------
1. Win+R 输入 sysdm.cpl 回车
2. 「高级」→「环境变量」
3. 在「用户变量」点「新建」
   变量名：GEMINI_API_KEY
   变量值：在 https://aistudio.google.com/apikey 申请的 Key
4. 全部确定
5. 关闭并重新打开 cmd / Cursor 终端 / 双击 bat 的窗口

验证
----
  py -3.12 components\check_env.py

应显示 [OK] GEMINI_API_KEY ...

同步 GitHub / 备份
------------------
- 整个项目目录可安全 push，Key 不在任何项目文件里
- 每台电脑、每个 Windows 用户各自设置 GEMINI_API_KEY
- 模型与配音选项（不含 Key）：components\config.bat

English summary
---------------
Set user env var GEMINI_API_KEY in Windows (sysdm.cpl -> Environment Variables).
No .env or key files in the repo. See check_env.py to verify.
