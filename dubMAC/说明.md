# dubMAC — Mac 配音流水线说明

本文件夹是 **Windows `components` 的 Mac 便携副本**，含最新脚本与依赖说明。  
将整个 `dubMAC` 拷到 Mac（U 盘 / iCloud / Git）即可使用。

> **Windows 侧更新脚本后**，在项目根目录执行：  
> `powershell -File sync_to_dubMAC.ps1`  
> 然后再把 `dubMAC` 同步到 Mac。

---

## 二、Mac 环境准备

### 1. 安装 Homebrew（若尚未安装）

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

### 2. 依赖对照表

| 用途 | 必需 | macOS 安装 | 验证 |
|------|------|------------|------|
| Python 3.12 | 完整配音流水线 | `brew install python@3.12` | `python3.12 --version` |
| ffmpeg / ffprobe | 全部 | `brew install ffmpeg` | `ffmpeg -version` |
| tkinter（图形选文件夹） | 合并工具建议 | `brew install python-tk@3.12` | 运行 `--pick-folder` 能弹窗 |
| pip 包（edge-tts、kokoro、notebooklm-py 等） | 完整配音 / NotebookLM | 见下文第三、八节 | `python3.12 check_env.py` |

**一键安装系统依赖：**

```bash
brew install python@3.12 ffmpeg python-tk@3.12
```

### 3. Python 包（仅完整配音需要）

```bash
cd /path/to/dubMAC/components
python3.12 -m pip install -r requirements.txt
python3.12 check_env.py
```

`merge_dub_tool` **不需要** pip，仅需 Python 标准库 + ffmpeg。

### 4. 可选：Gemini API

若 `tubeget.config.json` 中 `gemini_rewrite: true`，在 Mac 上创建：

```bash
# components/tubeget.secrets.json（勿提交 Git）
{"gemini_api_key": "你的密钥"}
```

或运行 `python3.12 run_batch_course.py --api-keys` 交互配置。

## 三、使用方式

### A. 完整流程：字幕 → 配音 MP3 → 成片 _C.mp4

每个文件夹放：**原视频** + **中文字幕**（`.zh-Hans.srt` / `.zh-CN.srt`）。

```bash
cd /path/to/dubMAC
chmod +x dub_local.sh
./dub_local.sh "/path/to/你的视频文件夹"
```

或直接：

```bash
cd /path/to/你的视频文件夹
python3.12 /path/to/dubMAC/components/run_batch.py
```

**课程多章节**（`components` 下多个子文件夹）：

```bash
cd /path/to/dubMAC/components
python3.12 run_batch_course.py --no-dialog
# 只跑某章：--folders "2" 或 --folders "1,3"
```

完成后查看 **PIPELINE PERFORMANCE REPORT**（各阶段耗时统计）。

### B. 仅合并：已有配音 + 原视频 → _C.mp4

适用：Windows 已生成 `_C.mp3` 或 `.mp3`，Mac 上只合并成片。

```bash
cd /path/to/dubMAC/merge_dub_tool
chmod +x merge_dub_videos.sh
./merge_dub_videos.sh
```

| 选项 | 作用 |
|------|------|
| 1 | 图形选文件夹 + **预览**（不写文件） |
| 2 | 图形选文件夹 + **正式合并** |
| 3 | 手动输入目录 |

命令行：

```bash
python3.12 merge_dub_videos.py --pick-folder --dry-run   # 预览
python3.12 merge_dub_videos.py --pick-folder             # 合并
python3.12 merge_dub_videos.py "/path/to/课程目录"
```

**配对规则（摘要）**：同目录内去掉下载序号（`2-` / `2标题`）、忽略开头 5 字后比较；优先用 `.mp3` / `_C.mp3` 作配音；合并以视频时长 +0.2s 为上限，避免截断最后一句话。

## 四、NotebookLM 全自动翻译 + 配音（路线 A · 实验）

适用：Udemy 等 **英+中双语字幕** → NotebookLM 翻译润色 → Edge TTS → `_C.mp4`。

**环境（除第三节外还需）：**

```bash
python3.12 -m pip install "notebooklm-py[browser]" rookiepy
python3.12 -m playwright install chromium
```

Playwright 浏览器缓存路径（Mac）：`~/Library/Caches/ms-playwright/`（脚本会自动检测，无需手工配置）。

**一次性登录：**

```bash
cd /path/to/dubMAC
chmod +x notebooklm_dub_setup.sh notebooklm_dub_translate.sh
./notebooklm_dub_setup.sh
```

**批量处理（一次提交整文件夹，脚本内自动分批/分段/断点续跑）：**

```bash
./notebooklm_dub_translate.sh "/path/to/课程目录"
# 仅翻译不配音：
./notebooklm_dub_translate.sh --no-dub "/path/to/课程目录"
```

| 特性 | 说明 |
|------|------|
| 大批量 | 自动按文件、按字幕条拆分，批间间隔 + 重试 |
| 断点续跑 | 同命令重跑，读 `_notebooklm_progress.json` 跳过已完成 |
| 双语发现 | 支持 `*.bilingual.srt` 或 `en_US.srt` + `zh-CN.srt` 自动合并 |

**仅配音（Windows 已翻好字幕）：**

```bash
./quick_bilingual_dub.sh "/path/to/课程目录"
```

## 五、主要配置（`components/tubeget.config.json`）

| 配置项 | 当前默认 | 说明 |
|--------|----------|------|
| `engine` | `edge+kokoro` | Edge 主合成，失败 Kokoro 补全 |
| `edge_ipv4_only` | `true` | Windows 防 IPv6 断连；Mac 一般可保持 |
| `edge_segment_mode` | `true` | 分段批量 Edge（按字数切段 + 异步并发） |
| `edge_segment_profile` | `auto` | `small`/`medium`/`large`/`auto`（先小段试跑再加大） |
| `edge_segment_chars_small` | `280` | 试跑段约 1～2 段字幕 |
| `edge_segment_chars_medium` | `420` | 试跑成功后默认段长 |
| `edge_segment_concurrency` | `4` | 同时在飞请求数（Semaphore） |
| `dub_batch_merge_size` | `0` | 分段模式下由 Edge 切段，勿与句数合并叠加 |
| `dub_split_by_sentence` | `false` | 勿改 `true`，否则会一句一顿 |
| `require_complete_dub` | `true` | 须全部合成成功才出 MP3 |
| `baseline_playback_speed` | `1.25` | 整体提速 |
| `max_playback_speed` | `1.5` | 单句变速上限 |

Mac 与 Windows **可共用同一份** `tubeget.config.json`。

## 七、常见问题

**Q：合并进度卡在 2.x% 不动？**  
A：先 Ctrl+C 结束，更新到最新 `merge_dub_videos.py`（已修 stderr 管道卡死）。确认配音是 `_C.mp3` 而非 YouTube 整段 `.mp4`。

**Q：弹窗选不了文件夹？**  
A：`brew install python-tk@3.12`，或命令行直接传路径。

**Q：配音未齐就停了？**  
A：再运行一次 `./dub_local.sh`，会自动续跑失败句（`--retry-failed`）。

**Q：NotebookLM 登录后仍报 Chromium 找不到？**  
A：执行 `python3.12 -m playwright install chromium`。Mac 浏览器在 `~/Library/Caches/ms-playwright/`，不是 Windows 的 `%LOCALAPPDATA%`。

**Q：Cursor 聊天记录能带到 Mac 吗？**  
A：不能。请拷 `dubMAC` 文件夹；在 Mac 打开后让 Agent 阅读本 `说明.md`。
