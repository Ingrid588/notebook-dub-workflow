【用途】把本文件内容复制到 Google NotebookLM，并上传整门课的双语字幕（.srt）。
让 AI 归纳「口播压缩策略」，导出 JSON 后交给配音脚本导入。

────────────────────────────────────────
请复制以下 Prompt 到 NotebookLM：
────────────────────────────────────────

你是课程配音字幕编辑。我已上传双语字幕（每段通常一行英文 + 一行中文）。

## 第一步：找出「长句」
对每条字幕：
- 统计英文字母+数字个数 en_chars
- 统计中文汉字个数 zh_chars（不含空格）
- 若 zh_chars > en_chars × 1.5，标记为「长句」

## 第二步：分析这些长句为什么长
不要逐条重写全部字幕。只针对长句，归纳反复出现的模式，例如：
- 多余套话（「我们需要」「实际上」「在这种情况下」）
- 书面语可改口语（「进行配置」→「配置」）
- 可删连接词（「以便」「从而」「也就是说」）
- 并列句可合并或删次要分句
- 不要动专有名词（AWS、S3、API、IAM 等）

## 第三步：输出「压缩策略」JSON
请严格只输出一个 JSON 代码块，格式如下（不要 markdown 说明文字）：

```json
{
  "version": 1,
  "source": "notebooklm",
  "course": "课程名称",
  "notes": "一两句总结本课翻译的冗长习惯",
  "drop_phrases": ["可整段删掉的赘词，从长到短"],
  "literal_replacements": [["原短语", "替换为"], ["进行设置", "设置"], ["来实现", ""]],
  "regex_replacements": [["，并且", "，"], ["的是", "是"]]
}
```

规则：
- drop_phrases：字符串列表，命中则删除
- literal_replacements：[[原, 新]]，新可为空字符串表示删除
- regex_replacements：Python 正则，尽量少、要安全
- 不要输出单条字幕的改写结果，只输出可复用策略

────────────────────────────────────────
导入到配音工具：
────────────────────────────────────────

py -3.12 run_batch_course.py --import-zh-strategy 你的策略.json
