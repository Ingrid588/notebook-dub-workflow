术语表文件夹说明
================

用途
----
1. Gemini / NotebookLM 提示词注入（已有）
2. 本地双语字幕术语校正 → 再配音（零 API 成本）

CSV 列说明
----------
必填：中文、English（或其它语言列）
可选：
  分类     — 塔罗 / 星座 / 相位 等，便于维护
  常见误译 — YouTube 机翻常出现的错误中文，用 | 分隔多个
             例：大阿卡那|主要阿卡纳|大阿卡纳

文件清单（按加载顺序）
----------------------
01_tarot_cards.csv      — 78 张韦特塔罗牌名
02_astrology.csv        — 占星：星座、行星、宫位、相位
03_tarot_general.csv    — 塔罗通用：牌阵、正逆位、解读用语
04_spirituality.csv     — 灵性/爱情占卜常用词
05_elements_modalities.csv — 四元素、三模式、星座属性

旧文件（文件名以 - 开头）已弃用，脚本会自动跳过。

维护建议
--------
- 发现 YouTube 新误译：在对应行「常见误译」追加，用 | 分隔
- 新牌名/占星词：按分类追加行，English 与视频英文字幕一致即可
- 改完可运行：apply_glossary.bat 对文件夹批量校正字幕
