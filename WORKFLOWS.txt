================================================================================
  两条路线 + 成本策略
================================================================================

【总原则】翻译解决绝大多数问题，不靠 AI 微调。

  · Gemini 只在「翻译层」调用一次（fit_translate.bat）
  · 配音阶段（commercial_dub_*）不再送 Chunk / Speech / TTS 后 Gemini
  · 剩余约 1%：本地规则压缩 + 加速；仍失败则保留全长或静音

┌─ 路线 A：学习实验（NotebookLM，免费）────────────────────────────────────┐
│ NotebookLM 译字幕 → quick_bilingual_dub.bat                              │
│ 全程无 Gemini API                                                        │
└──────────────────────────────────────────────────────────────────────────┘

┌─ 路线 B：商用验证（Gemini 仅一步）────────────────────────────────────────┐
│ 1. fit_translate.bat           ← 唯一 Gemini 调用（产出 fit-dub.srt）    │
│ 2. commercial_dub_test.bat     ← 只 TTS + 脚本，不再 AI                  │
└──────────────────────────────────────────────────────────────────────────┘

配置项（tubeget.config.json）：
  dub_translate_once: true     主开关（默认开）
  gemini_chunk_translate: false
  gemini_dub_rewrite: false
  gemini_post_tts_rewrite: false

关闭 translate_once 才会恢复旧的多轮 Gemini（不推荐商用）。
